# Игра «Монстры на болоте»

## Описание

Программа реализует текстовую игру «Монстры на болоте».

По условию на болоте спрятано четыре монстра. Болото представляет собой квадратное поле с координатами от `(0; 0)` до `(9; 9)`. Игроку нужно поймать всех монстров за десять попыток.

Решение соответствует уровню оценки **«Хорошо»**, потому что реализованы:

- текстовый интерфейс;
- подсказки расстояний до оставшихся монстров;
- дополнительный ход при угадывании координат монстра.

## Правила игры

1. Игрок вводит координаты клетки: `x` и `y`.
2. Если в выбранной клетке есть монстр, он считается пойманным.
3. При поимке монстра попытка не тратится.
4. Если в клетке монстра нет, количество попыток уменьшается на 1.
5. После каждого хода программа показывает расстояния до оставшихся монстров.
6. Игра завершается победой, если все монстры пойманы.
7. Игра завершается поражением, если попытки закончились.

## Формула расстояния

В программе используется расстояние по прямой между двумя клетками:

```text
sqrt((x2 - x1)^2 + (y2 - y1)^2)
```

## Запуск программы

Для запуска требуется Python 3.10 или выше.

```bash
python main.py
```

## Настройки игры

В начале файла `main.py` можно изменить параметры игры:

```python
FIELD_SIZE = 10
MONSTERS_COUNT = 4
ATTEMPTS_COUNT = 10
```

Где:

- `FIELD_SIZE` — размер стороны квадратного поля;
- `MONSTERS_COUNT` — количество монстров;
- `ATTEMPTS_COUNT` — количество попыток.

По умолчанию используются параметры из задания:

```text
Поле: 10 x 10
Монстры: 4
Попытки: 10
```

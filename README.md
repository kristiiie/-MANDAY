# Персональный ассистент по расчёту MANDAY

Консольная программа на Python рассчитывает MANDAY — стоимость одного рабочего дня, достаточную для покрытия годовых расходов. Решение также показывает дневную ставку с учётом выбранного налогового сценария: без налога, НДФЛ или НПД.

## Возможности

- расчёт календарных выходных по выбранному году;
- добавление нерабочих дат по производственному календарю;
- добавление персональных выходных, отпуска и разгрузочных дней;
- ввод расходов по категориям: ежемесячные, ежегодные и разовые;
- настройка валюты и курса к рублю;
- редактирование ранее введённых данных;
- расчёт базового MANDAY;
- расчёт требуемого валового MANDAY с учётом НДФЛ или НПД;
- проверка плановой дневной ставки;
- сохранение и загрузка данных в JSON.

## Требования

- Python 3.10 или новее.
- Внешние библиотеки не требуются.

## Запуск

```bash
python main.py
```

## Как пользоваться

1. Запустите программу.
2. Выберите пункт `1. Создать новый расчёт`.
3. Укажите календарный год.
4. Выберите валюту расчёта. Для налогового блока программа использует пересчёт в рубли, поэтому для валюты, отличной от RUB, нужно указать курс.
5. Добавьте нерабочие даты. Можно загрузить базовые праздничные даты РФ без переносов, а затем вручную добавить перенесённые выходные из производственного календаря.
6. Добавьте персональные нерабочие даты: отпуск, больничные, разгрузочные дни, учебные дни.
7. Введите расходы по категориям.
8. Выберите налоговый режим.
9. При необходимости укажите плановую ставку за день, чтобы увидеть годовой доход, налог и баланс после расходов.

## Формула базового расчёта

```text
MANDAY = годовые расходы / количество рабочих дней
```

Количество рабочих дней определяется так:

```text
рабочие дни = все дни года - календарные выходные - дополнительные нерабочие даты - персональные нерабочие даты
```

Если одна и та же дата попадает в несколько списков, программа считает её один раз.

## Налоговые режимы

### Без налога

Программа считает только базовый MANDAY без налоговой надбавки.

### НДФЛ

Для основных доходов налоговых резидентов РФ применяется прогрессивная шкала. Программа считает налог по ступеням: повышенная ставка применяется только к части дохода, которая превышает предыдущий порог.

### НПД

Для налога на профессиональный доход поддержаны ставки 4% для доходов от физических лиц и 6% для доходов от ИП и организаций. Для смешанного сценария пользователь задаёт долю дохода от физических лиц. Программа предупреждает, если расчётный доход превышает лимит НПД 2 400 000 рублей в год.

## Сохранение данных

В главном меню выберите пункт `4. Сохранить данные в JSON`. Данные сохраняются в файл `manday_project.json` рядом с программой.

Для восстановления расчёта выберите пункт `5. Загрузить данные из JSON`.

## Пример контрольного расчёта

Исходные условия:

- год: 2026;
- валюта: RUB;
- добавлены базовые праздничные даты РФ без переносов;
- персональный отпуск: 2026-07-01 — 2026-07-14;
- расходы: демонстрационный набор из программы;
- налоговый режим: НПД, клиенты — ИП и организации;
- плановая ставка: 12 000 рублей.

Ожидаемое поведение:

- программа посчитает календарные выходные автоматически;
- праздничные и персональные даты, попавшие на субботу или воскресенье, не будут задвоены;
- в результате появятся базовый MANDAY, MANDAY с учётом налога, налог по плановой ставке и годовой баланс.

## Ограничения

Базовые праздничные даты РФ в программе не заменяют официальный производственный календарь с переносами выходных дней. Перенесённые выходные необходимо добавить вручную через меню редактирования нерабочих дат.
